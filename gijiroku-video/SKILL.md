# gijiroku-video（動画風の議事録）

議事録を 1 分〜3 分の縦型アニメにする。場面ごとに「見出し → 図や数字 → 一言」の順で要素が出て、ブラウザが読み上げる。
できるのは HTML 1 枚だけ。音声ファイルも API キーも要らない。

## 手順

1. **中身を決める。** 議事録を読み、1 場面 1 メッセージで 5〜10 場面にする（1 場面およそ 15〜25 秒、3 分なら 8〜9 場面）。
   - 1 場面目は会議名・会議日・決まったことの数。最後の場面は「次にやること」（担当・期限は議事録で合意されたものだけ）。
   - 数字・人名・日付は議事録に書いてあるものだけを使う。推測で足さない。聞き取りがあやしい言葉（「聞き取り確認」など）は使わないか、「要確認」と書く。
   - 会議日が分からない時は、作る前に利用者に聞く。
2. **土台をコピーする。** `assets/template.html` をそのまま複製し、次の場所だけ書き換える。
   - `<title>`（「10/1 営業会議」のような短い名前）と、ヘッダーの `会議名｜YYYY-MM-DD`
   - `<svg id="stage">` の中の `<g class="scene" ...>`（見本の 3 場面は消して置き換える）
   - 右側の目次 `#chapters`（場面と同じ数・同じ順。各場面の数字は文字でも書く）と、`.side` の見出し・説明・出典
3. **場面の書き方。**
   - `<g class="scene" data-dur="秒" data-title="帯の見出し" data-say="読み上げる文">`。1 場面目だけ `class="scene on"`。
   - `data-title` は 14 文字まで（帯は自動で描かれる）。
   - `data-say` は 60〜140 文字。数字は読み方で書く（「百二十件」「十月八日」）。英字や読み間違えやすい名前はカタカナ・ひらがなにする。文は「。」で区切る。
   - `data-dur` ＝ `data-say` の文字数 ÷ 7 ＋ 2（切り上げ）。読み上げが終わるまで次の場面へは進まない。
4. **座標と動き。**
   - 画面は viewBox 720×1280。帯が y70〜160、本文は y220〜1200、左右の余白は 60。
   - 文字の大きさ N の時、1 行はおよそ 600÷N 文字まで。はみ出す時は 2 行に分けるか小さくする。
   - 動きはクラスで付ける。`style="--d:1.5s"` で出る時刻（秒）をずらし、読み上げでその言葉が出るころに合わせる。
     `fade` 下から出る（文章）／`pop` ぽんと出る（数字・ラベル）／`gy` 棒が下から伸びる／`gx` 横棒が左から伸びる／
     `draw` 線を描く（`pathLength="1"` を付ける）／`stamp` 判子（注意・締め切り）
   - 棒グラフの長さは値に比例させ、目盛りや数字と食い違わせない。
5. **色**（丸昇）。青 `#1d4ed8`、明るい青 `#2563eb`、淡い青 `#dbeafe`、文字 `#0b1220`、補足 `#64748b`、グレー `#dbe1ea`、緑 `#00ab0f`（線・丸印など小さい面だけ）。
   文字色は要素の `fill` 属性で指定する。青地の上の文字は必ず白 `#ffffff`。
6. **出す。**
   - Claude アプリ: 仕上げた HTML の全文を HTML の Artifact として出す。
   - Codex / Claude Code: `YYYY-MM-DD-会議名.html` として保存し、ブラウザで開く。
   - 1 回だけ全場面を見て、文字の重なり・はみ出しを直す。
7. **伝える。** 利用者には「▶ 読み上げつきで再生」ボタンから再生するよう伝える（読み上げはボタンを押した後にしか鳴らない）。

## 守ること

- 社外秘の数字・個人名が入ったページは社内だけで共有する。公開するかは作った人が決める。
- 議事録に無い決定・担当・期限を作らない。
- 読み上げの声はブラウザと OS で変わる（Mac の Safari・Chrome、Windows の Edge なら日本語の声がある）。声が出ない環境でも、文字と動きだけで中身が分かるようにする。
