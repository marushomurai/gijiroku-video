議事録を動画にするスキル

議事録を貼って「議事録を動画にして」と言うだけで、動く・しゃべる議事録ができます。

Codex を使っている人

Codex に入れる（1分）

  1. 下の青いボタンを押す（文字がコピーされます）
    コピーしました $skill-installer install https://github.com/marushomurai/gijiroku-video/tree/main/gijiroku-video
  2. Codex を開いて、いつも質問を書くところに貼り付けて送る（Mac は ⌘＋V）
  3. 「入れました」と返事が来たら、Codex を一度閉じて開き直す
Claude を使っている人

Claude に入れる（2分）

  1. 下の青いボタンを押す（ファイルがダウンロードされます。開かずにそのままでOK）
    ダウンロードする
  2. このボタンを押して、Claude の「スキル」の画面を開く
    スキルの画面を開く
    Claude アプリの中なら「カスタマイズ（Customize）」→「スキル（Skills）」と同じ画面です
  3. 「＋」→「スキルを作成（Create skill）」→「スキルをアップロード（Upload a skill）」を押す
  4. さっきダウンロードした gijiroku-video.zip を選ぶ（「ダウンロード」フォルダに入っています）
  5. 一覧に gijiroku-video が出て、スイッチがオンになっていれば完了
入れたあと

使い方

  1. 議事録やメモを貼って「議事録を動画にして」と送る
  2. できたページの「▶ 読み上げつきで再生」を押す

うまく入らない時は、この画面を見せて村井さんに聞いてください。社外秘の内容が入った動画は社内だけで見せてください。
